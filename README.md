🧦 Missing Socks Detector

«An AI-powered solution to a problem that absolutely does not need AI.»

😂 About the Project

Missing Socks Detector is a fun and completely useless AI-inspired web experience that pretends to help users find their missing socks.

Upload a picture of your sock, wait for the dramatic 99% AI analysis, and get thrown into a chaotic 30-second sock-catching game where the socks fall, dodge, teleport, and escape from your hand.

After all that effort... you still don't find the sock. 🧦💀

🎮 How It Works

1. 📸 Scan Your Sock — Upload a picture using the SCAN SOCK button.

2. 🤖 AI Analysis — Watch the dramatic scanner reach 99%.

3. 🖤 Unexpected Blackout — The screen suddenly goes black.

4. 🧦 Sock Hunt — Multiple socks start falling from the top.

5. 🖐️ Try to Catch Them — The socks dodge and escape your hand.

6. ⏱️ 30-Second Challenge — Catch them before the timer runs out.

7. 😂 Final Verdict — The AI announces:
   
   "thekkoott nokki ninnoo"

✨ Features

- 🧦 Interactive falling-sock game

- 🖐️ Animated catching hand
- 💬 Funny sock dialogues

- 🤖 Fake AI scanning animation
